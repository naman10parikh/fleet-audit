# Muster: brand

## Name

**Muster.** A muster is the gathering of a ship's crew, or a fleet's, for inspection and a roll call; to pass muster
is to meet the standard. fleet-audit gathers your repositories, calls the roll of the surfaces each one should have,
and tells you which pass muster. The tool keeps the plain name fleet-audit; Muster is its persona.

## Tagline

> **Every repository answers the roll.**

## The symbol in the work

| Brand element | What it maps to in the work |
| --- | --- |
| The roll call | The checks: one line per surface, each pass, missing or unknown. |
| The muster roll | The Markdown report over many repositories. |
| Passing muster | Every decidable check passes and the scrub is clean. |
| Issuing kit | `fleet-audit kit`: what can be issued in one step is issued. |

## Look

Plain text and Markdown tables. A missing check is bold; a passing one stays quiet.

## One line

fleet-audit tells you, for every repository, what a coding agent will find, what it will miss, and what one command
fixes.
